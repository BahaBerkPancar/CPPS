# CPPS: 42 C++ Modules 02-09

- `cpp02`: fixed-point numbers, operator overloading, a BSP point test
- `cpp03`: ClapTrap/ScavTrap/FragTrap/DiamondTrap inheritance
- `cpp04`: Animal polymorphism, abstract classes, deep copy with Brain
- `cpp05`: Bureaucrat, Form and Intern, with exceptions
- `cpp06`: ScalarConverter, Serializer, and dynamic_cast identification
- `cpp07`: function and class templates
- `cpp08`: easyfind, Span, MutantStack
- `cpp09`: BitcoinExchange, RPN and PmergeMe on STL containers

Build one exercise with `make -C cpp0X/exNN` (for example `make -C cpp04/ex01`). Everything is compiled with `-std=c++98 -Wall -Wextra -Werror`.

A 42 İstanbul project.
